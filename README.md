I enjoy understanding how software works beneath the surface — from application logic and API design to database interactions, shell automation, and the systems that run applications.

My approach is simple: learn by building, understand the fundamentals, and keep improving the quality of what I ship.

## 🚀 Active Project — JumuiaX

<h3 align="center">
  <a href="https://jumuiax.com">JumuiaX — Discover. Book. Experience.</a>
</h3>

<p align="center">
  <a href="https://jumuiax.com/about">
    <img src="https://img.shields.io/badge/ABOUT%20THE%20PROJECT-Read%20Our%20Story-0D1117?style=for-the-badge&logo=googlechrome&logoColor=58A6FF" alt="Read about JumuiaX">
  </a>
  <a href="https://jumuiax.com">
    <img src="https://img.shields.io/badge/LIVE%20PLATFORM-Explore%20JumuiaX-0D1117?style=for-the-badge&logo=googlechrome&logoColor=58A6FF" alt="Explore JumuiaX">
  </a>
</p>

**JumuiaX** is an active Kenyan project I'm building: a local-services marketplace designed to connect customers with salons, barbers, spas, wellness professionals, and other service businesses.

The platform aims to make it easier for customers to discover and book services while helping businesses manage their operations and reach more customers.

What makes this project meaningful to me is its evolution from a simple system into a broader marketplace ecosystem.

- 🧩 **Marketplace:** Connecting customers, businesses, and professionals
- 📅 **Bookings:** Helping customers discover services and manage appointments
- 🏢 **Business operations:** Supporting service listings, staff, branches, schedules, and bookings
- 🏗️ **Systems thinking:** Exploring the engineering challenges involved in growing a platform from a single-business system into a multi-tenant ecosystem

JumuiaX is where I get to turn ideas into working software and learn from the practical challenges of building a real product.
